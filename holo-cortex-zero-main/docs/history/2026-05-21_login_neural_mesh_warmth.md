# 2026-05-21 登录页神经网背景升温

## 目标

用户确认登录页神经网背景高级感足够，但整体偏冷。目标是在不破坏安静神经连接重点的前提下，轻微增加温度。

## 修改范围

- 只修改登录页背景调色。
- 不修改字体、字距、输入节奏。
- 不修改 logo、品牌文案、登录框位置。
- 不修改神经节点数量、连接结构、登录逻辑。

## 修改内容

- 将主底色从纯冷黑青轻微推向暖黑：
  - `deepInk: #010305 -> #030202`
  - `midnight: #02070d -> #08060b`
- 将部分冷靛蓝/紫色调稍微暖化：
  - `mutedIndigo: 102,126,186 -> 118,124,178`
  - `softViolet: 126,104,154 -> 142,104,132`
- 将金色突触更温润：
  - `agedGold: 166,132,82 -> 185,139,82`
- 新增低透明度 `emberRose` 与右下角 `emberWash`，只做氛围升温，不提高节点亮度。
- 暖色连接比例从约 `1/9` 提高到约 `1/6`，但仍保持低透明度。

## 保护项复核

- 品牌标题字距保持 `0.28em`。
- slogan 字距保持 `0.08em`。
- 输入框字距保持 `0.06em`。
- CTA 字距保持 `0.18em`。
- logo：`left: 7vw; top: 10vh`
- 品牌文案：`left: 42vw; top: 40vh`
- 登录框：`right: 12vw; bottom: 5vh`

## 验证

```bash
pnpm --dir frontend exec eslint src/pages/login/index.tsx
pnpm --dir frontend build
```
