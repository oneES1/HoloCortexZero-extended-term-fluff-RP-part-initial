# 2026-04-01 Docker 部署分享包

## 目标
- 未来线下小范围分享时，只分享可部署的 Docker 源码包
- 不分享 Git 历史
- 不分享运行数据、登录态、日志、密钥

## 本次新增
- 根目录部署模板：`/path/to<CONTAINER_WORKSPACE_DIR>/.env.share.example`
- 根目录部署说明：`/path/to<CONTAINER_WORKSPACE_DIR>/README_DEPLOY.md`
- 根目录打包脚本：`/path/to<CONTAINER_WORKSPACE_DIR>/make_docker_release_bundle.sh`

## 打包范围
打包时仅保留：
- `docker-compose.yml`
- `.env.share.example`
- `README_DEPLOY.md`
- `self_image/`
- `holo-cortex-zero-main/`

## 自动清理
脚本会删除：
- `.git`
- `.venv`
- `node_modules`
- `__pycache__`
- `.env`
- `*.log`
- `holo-cortex-zero-main/data`
- `holo-cortex-zero-main/frontend/dist`
- `holo-cortex-zero-main/stage1_smoke`

## 使用方式
- `cd /path/to<CONTAINER_WORKSPACE_DIR>`
- `./make_docker_release_bundle.sh`
- 默认输出：`/tmp/hcz_release/hcz-docker-deploy-YYYYMMDD.tar.gz`

## 分享包使用方步骤
- 解压
- 复制 `.env.share.example` 为 `.env`
- 修改 `.env`
- 执行：
  - `docker compose build holo_cortex_zero`
  - `docker compose up -d`
