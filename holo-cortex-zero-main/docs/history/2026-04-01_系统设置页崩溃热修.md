# 2026-04-01 系统设置页崩溃热修

## 现象

打开“系统设置”页面时前端直接崩溃。

## 根因

在前一轮 `ConfigTable` 分层收口中，`src/components/common/ConfigTable.tsx` 仍然在主干里使用了：

- `ExpandMoreIcon`
- `ExpandLessIcon`

但导入被误删，导致当系统设置中的配置项进入可展开分支（如 `list` / `complex` 配置）时，运行时触发未定义错误并崩溃。

## 修复

仅做最小修复：

- 在 `src/components/common/ConfigTable.tsx` 恢复 `ExpandMoreIcon` / `ExpandLessIcon` 导入
- 未改动任何业务逻辑、保存逻辑、渲染分支或接口定义

## 验证

- `cd /path/to/source-root/frontend && env -u NODE_OPTIONS pnpm exec eslint src/components/common/ConfigTable.tsx`
- `cd /path/to/source-root/frontend && env -u NODE_OPTIONS pnpm build`

## 回滚点

本次热修应独立提交，便于单独回退。
