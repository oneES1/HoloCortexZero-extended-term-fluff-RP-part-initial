# 2026-05-12 隐藏 prompt inject 高级参数

## 背景

系统设置页仍展示一批 memory prompt inject 的 Stage2 / legacy 调参字段。这些字段仍被运行逻辑读取，但不适合作为常规前端配置项展示。

## 修改

仅在 `CoreConfig` 字段的 `json_schema_extra` 中设置 `is_hidden=True`，不删除字段，不改变默认值，不改变 memory runtime 读取逻辑。

隐藏字段共 15 个：

- `PROMPT_INJECT_RECENT_FUTURE_GRACE_MINUTES`
- `PROMPT_INJECT_STAGE2_UNSET_THRESHOLD_LT`
- `PROMPT_INJECT_STAGE2_DEFAULT_THRESHOLD_FALLBACK`
- `PROMPT_INJECT_STAGE2_RECENT_THRESHOLD`
- `PROMPT_INJECT_STAGE2_STATIC_SCORE_THRESHOLD`
- `PROMPT_INJECT_STAGE2_MAX_STATIC_ITEMS`
- `PROMPT_INJECT_STAGE2_MAX_CONTEXT_ITEMS`
- `PROMPT_INJECT_STAGE2_MAX_INTENT_ITEMS`
- `PROMPT_INJECT_STAGE2_MAX_INTENTS`
- `PROMPT_INJECT_STAGE2_CONCURRENT_SEARCH`
- `PROMPT_INJECT_STAGE2_THIRD_PARTY_RECENT`
- `PROMPT_INJECT_STAGE2_THIRD_PARTY_TOTAL`
- `PROMPT_INJECT_LEGACY_STATIC_SCORE_THRESHOLD`
- `PROMPT_INJECT_LEGACY_DEFAULT_THRESHOLD_FLOOR`
- `PROMPT_INJECT_LEGACY_RECENT_THRESHOLD`

uv run python -m compileall holo_cortex_zero/core/config.py
