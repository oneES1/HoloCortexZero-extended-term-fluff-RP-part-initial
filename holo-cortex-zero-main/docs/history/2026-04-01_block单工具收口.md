# 2026-04-01 block 单工具收口

## 目标
- 删除公开面的 `block_prevent_trigger`
- 只保留一个 block Tool，Bot 侧只传 `user_id`
- 拉黑后统一走固定默认时长的完整屏蔽

## 本次修改
- `tool_runtime/tools/block.py`：删除 `block_prevent_trigger` 公开常量与处理函数
- `tool_runtime/tools/block.py`：将 `block_full` 收口为唯一 block Tool，默认直接写入 `full_block`
- `tool_runtime/tools/block.py`：删除禁止触发开关与永久屏蔽分支，只保留默认时长配置
- `tool_runtime/tools/__init__.py`：移除 `block_prevent_trigger` 导出
- `holo_cortex_zero/services/tools/migrated/__init__.py`：取消 `block_prevent_trigger` 注册
- `docs/guides/tool-integration.md`：同步删除 `block_prevent_trigger`

## 影响分析
- 模型侧公开 Tool 从两个缩成一个，减少误选和分支歧义
- 旧存量记录里如果存在 `prevent_trigger`，再次对同一用户执行 `block_full` 时会清掉旧状态后切到完整屏蔽
- 用户表的 `prevent_trigger_until` 字段未删除，仅不再通过公开 Tool 写入，避免扩散式改库
- 宿主桥接 `apply_user_block/clear_user_block` 主干未分叉，仍兼容历史记录的 `block_type`
