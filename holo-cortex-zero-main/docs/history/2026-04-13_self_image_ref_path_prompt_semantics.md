# 2026-04-13 自设图参考路径提示语义修正

## 现象

高级 context 下，自设图参考路径被直接以纯路径文本注入 system prompt：

- 没有说明这些路径的用途。
- 三个路径使用换行拼接，传给部分模型时可读性一般，容易看起来像一整段糊在一起的原始文本。

## 根因

`holo_cortex_zero/services/agent/run_agent_v2.py` 中 `_get_self_image_data()` 对导出的 `exported_paths` 仅做了 `"\n".join(...)`，没有补充用途说明，也没有做更清晰的单行分隔语义。

## 修改

- 在路径文本最前面增加固定说明：`印象图调用路径，绘图等可用：`
- 三个路径改为单行输出，之间使用单个空格分隔，不再使用换行。
- 保持高级 context 才注入参考路径的既有边界不变。

## 影响范围

- 仅影响 system prompt 中“自设图参考路径”这一个文本片段。
- 不影响印象图 data URI 注入。
- 不影响普通用户 context。
- 不影响路径解析、文件读取、适配器路由与出站发送。

## 风险与回滚点

- 风险很小，属于提示词语义优化，不涉及协议结构改动。
- 如需回滚，只需恢复 `holo_cortex_zero/services/agent/run_agent_v2.py` 中 `ref_text` 的拼接方式。
