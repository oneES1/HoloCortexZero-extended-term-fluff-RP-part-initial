# 2026-05-20 登录页神经网降噪

## 问题

用户反馈上一版登录页背景太吵、太亮，视觉重点变成一堆亮点移动，神经连接不明显。

## 修改原则

- 只调整登录页背景动效层。
- 不修改 logo、品牌文案、登录框位置。
- 视觉重点从“亮点”改回“连接线”。

## 修改内容

- 节点数从 `118` 降为 `86`。
- 节点漂移速度从 `0.00008-0.00026` 降为 `0.000035-0.00012`。
- 节点漂移幅度从 `9-33px` 降为 `3-11px`。
- 节点尺寸从 `0.7-2.6px` 降为 `0.45-1.4px`。
- 删除连接线上的飞行光点，避免“亮点飞来飞去”。
- 连接线改为双层：
  - 暗底线：`1.65-2.2px`，低亮度。
  - 主连接线：`0.72-0.95px`，中低透明度。
- 画面底色与边缘遮罩加暗，降低整体亮度。

## 位置复核

- logo：`left: 7vw; top: 10vh`
- 品牌文案：`left: 42vw; top: 40vh`
- 登录框：`right: 12vw; bottom: 5vh`

## 验证

```bash
pnpm --dir frontend exec eslint src/pages/login/index.tsx
pnpm --dir frontend build
```

- `eslint src/pages/login/index.tsx` 通过。
- `vite build` 通过，转换模块数 `14084`，构建耗时约 `33.29s`。
