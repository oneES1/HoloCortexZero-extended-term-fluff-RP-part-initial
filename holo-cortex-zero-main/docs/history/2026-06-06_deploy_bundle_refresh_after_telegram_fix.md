# deploy 包刷新：同步 Telegram 修复

## 背景

源码已修复 Telegram 更新处理中的缺失方法调用问题，运行态也已完成热更新。外发 deploy 包仍需刷新，确保 latest 包包含当前 `main` 的修复版本。

## 操作

使用既有 deploy 包生成脚本重新生成发布包，并替换仓库中已跟踪的 latest 包：

- `hcz-docker-deploy-latest.tar.gz`

生成脚本仅执行本地复制、清理、默认配置种子生成、压缩与最小校验；未执行联网下载、依赖安装、镜像构建或运行态变更。

## 校验

已执行生成脚本内置校验：

- 排除 `.env`、日志、缓存、运行数据、依赖目录、开发脚本和内部文档目录。
- 确认默认配置种子存在。
- 确认发布说明文件存在。
- 确认默认 emoji 种子资源数量符合预期。

额外复核：

```bash
tar -tzf hcz-docker-deploy-latest.tar.gz
```

结果：压缩包可正常列出内容，latest 包已被新生成版本替换。

## 范围

本次只刷新 deploy 包及对应 history 记录，不修改运行态、不修改部署脚本、不修改源码逻辑。
