# 2026-04-01 block 工具简化与冗余移除

## 目标
- 删除 `unblock_user` 与 `list_blocked_users` 两个公开 Tool
- 简化剩余 block Tool 的入参，只保留 `user_id`
- 去掉 block 名单展示相关的冗余配置，减少模型上下文负担

## 本次修改
- `tool_runtime/tools/block.py`：删除 `unblock_user`、`list_blocked_users` 及对应常量
- `tool_runtime/tools/block.py`：将 `block_prevent_trigger`、`block_full` 的公开参数收敛为 `user_id`
- `tool_runtime/tools/block.py`：删除 `SHOW_BLOCKED_USERS_IN_PROMPT`、`MAX_PROMPT_DISPLAY_COUNT` 配置项
- `tool_runtime/tools/block.py`：收短 block Tool 返回文案，不再回填时长、原因、效果等额外文本
- `tool_runtime/tools/__init__.py`：移除已删除 Tool 的导出
- `holo_cortex_zero/services/tools/migrated/__init__.py`：取消已删除 Tool 的注册
- `docs/guides/tool-integration.md`：同步更新公开 Tool 清单

## 影响
- Bot 侧使用 `block_prevent_trigger`、`block_full` 时，现在只需要传 `user_id`
- 公开 Tool 集内不再提供解除屏蔽和查看屏蔽名单能力
- block Tool 执行结果更短，避免把屏蔽名单/附加说明继续塞回模型上下文
- 底层 `lookup_user` 仍兼容原有解析主干，但公开 Tool 面已收口，不再鼓励传 `adapter:id`
